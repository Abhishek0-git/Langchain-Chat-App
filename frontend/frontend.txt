Please generate the HTML, CSS, and vanilla JavaScript for a modern, dark-themed AI Document Assistant frontend. 

**1. General Architecture & Libraries**
* Use semantic HTML5.
* Do not use any frontend frameworks (React, Vue, etc.)—strictly vanilla HTML, CSS, and JS.
* Include FontAwesome via CDN for UI icons.
* Include Marked.js via CDN to parse Markdown in the chat window.

**2. Visual Layout & UI Structure**
The layout should be a responsive, full-screen flex container split into two main areas:
* **Sidebar (Left, fixed width):**
    * User Profile section at the top (Avatar, Name, "Online" status with a green dot, and a Logout icon).
    * A primary "New Chat" button.
    * A scrollable list of recent chat sessions. The active session should be highlighted with a left border accent.
* **Main Chat Area (Right, flex-grow):**
    * **Header:** A toggle button ("View Uploaded Files"). When clicked, it expands a panel underneath showing a list of uploaded files (with PDF/CSV icons and delete buttons) or loading states.
    * **Chat History:** A scrollable area for messages. User messages align right with a distinct background. AI messages align left, feature a robot avatar, and parse Markdown.
    * **Input Container (Fixed at bottom):** A form containing a hidden file input (triggered by a paperclip icon label), an auto-resizing textarea (multiline, expands as user types), and a submit/send icon button.
    * **Toast Container:** Fixed at the top right for temporary success/error notifications.

**3. Styling & Theme (CSS)**
* **Theme:** Deep dark mode. Use `#141419` for the main background, `#0d0d11` for the sidebar, and `#1e1e24` for surface elements.
* **Accent Color:** A neon purple/indigo (e.g., `#5e5ce6`) for buttons, active states, and AI avatars. 
* **Typography:** Clean sans-serif (system fonts).
* **Details:** Include custom sleek scrollbars, smooth hover transitions on all buttons, and a slight glassmorphism/blur effect on the chat header.

**4. Core Logic & Interactions (JavaScript)**
The API Structure (Backend Endpoints)**
The frontend must interact with the following backend endpoints:
* **Authentication:** * `POST /api/auth/login`: Accepts credentials, returns a session token.
  * `POST /api/auth/logout`: Clears the session.
* **Session Management:**
  * `GET /api/sessions`: Fetches session history.
  * `POST /api/sessions`: Creates a new blank session.
  * `GET /api/sessions/{session_id}`: Fetches past messages for a specific session.
* **File Management:**
  * `POST /api/upload`: Handles multipart/form-data file uploads.
  * `GET /api/files/{session_id}`: Retrieves the list of active files.
  * `DELETE /api/files/{file_id}`: Removes a file.
* **AI Interaction (Streaming):**
  * `POST /api/chat`: Accepts a JSON payload containing the user's `query` and `session_id`. The backend must return a chunked streaming response.

* **UI Interactions:** Auto-resize the textarea based on content. Submit the form on 'Enter' (but allow 'Shift+Enter' for new lines). Toggle the file header panel visibility.
* **Toast System:** Create a function to trigger slide-in/fade-out notifications (green for success, red for errors) that auto-remove after 5 seconds.
* **File Upload Logic:** Listen for file selection. Immediately show a loading spinner in the file panel, send the file via `fetch` as `multipart/form-data` to `/api/upload`, and update the UI to show the file name and a delete button upon success (or trigger an error toast on failure).
* **AI Chat & Streaming Logic:**
    * When the user submits a message, append it to the chat history and clear the input.
    * Append an AI message template with a loading spinner.
    * Make a `POST` request to `/api/chat` sending a JSON body with the query and session ID.
    * Use the Fetch API's `ReadableStream` (`response.body.getReader()`) and a `TextDecoder` to capture the AI's response chunk-by-chunk as it is generated by the server.
    * As chunks arrive, append them to a string and immediately pass the full string through `marked.parse()` to render the Markdown dynamically in the UI.
    * Auto-scroll to the bottom of the chat history as new text streams in.
